# LA VIE BELLE: INTERACTIVE WEBSITE UPGRADE
## Existing Website Enhancement, Not a Rebuild

Act as a senior frontend engineer, award-winning web designer and interaction designer.

I already have an existing website for La Vie Belle Cafe & Bakery. The current design, branding, typography, colour palette and overall structure are approved as the foundation.

Your task is to transform the existing website from a simple static presentation into a premium, interactive, visually engaging commercial cafe website.

**IMPORTANT: DO NOT REBUILD THE WEBSITE FROM SCRATCH.**

Inspect the existing project and preserve its current design identity.

Do not replace the existing design with a generic template.

The website should feel like a professionally developed website commissioned by a real hospitality business.

Keep:

# 2. MAKE THE WEBSITE FEEL ALIVE

The current website feels too static.

Add sophisticated micro-interactions throughout the website.

### Navigation
- Smooth sticky navigation.
- Elegant hover underline animations.
- Animated hamburger menu.
- Smooth mobile navigation opening and closing.
- Active navigation link indication.
- Smooth section scrolling.
- Subtle background transition when scrolling.

### Buttons

Every button must have a meaningful interaction.

Implement:
- Smooth colour transitions.
- Subtle hover movement.
- Animated arrow icons.
- Underline or border transitions.
- Press feedback when clicked.
- Proper focus states for keyboard accessibility.

Buttons should never look clickable but do nothing.

### Scroll animations

Add subtle reveal animations:
- Headings fade in and move slightly upward.
- Images reveal smoothly.
- Text blocks appear progressively.
- Section elements animate when entering the viewport.

Use Intersection Observer or an equivalent lightweight solution.

Animations must run smoothly and must not cause layout shifts.

Respect reduced-motion accessibility preferences.
